# AutoReach

AutoReach automatically identify business leads from platforms like **IndiaMART**, **TradeIndia**, and **ExportersIndia**, and sends them personalized introduction messages.

---

## ✨ Paid Version Features

- 🤖 Sends a predefined WhatsApp introduction message to new leads
- 🛠 Customizable message templates for better engagement
